# 순수튜브 계획

원칙: 유튜브의 기본 틀을 먼저 완성하고, 기능은 협의해서 하나씩 더한다.

## 1차: 기본 틀 (완료)
홈, 올리기, 자동 압축과 썸네일, 보기 화면, 검색, 분류, 정렬, 좋아요, 조회수, 댓글, 고치기·지우기, 저장 공간 표시

## 3차: 핵심 보기 (완료)
영상을 올리면 서버가 말소리를 글로 바꾸고(faster-whisper), AI(사내 Qwen)가 핵심 구간과 핵심 내용을 고른다. 원본 영상은 그대로 두고 건너뛰며 재생한다.

| 기능 | 비고 |
|---|---|
| 핵심만 보기 | 핵심 구간만 이어서 재생(H). 재생 막대 아래 파란 띠가 핵심 구간 |
| 핵심 내용 글 | 한 줄 요약 + 구간별 핵심 문장. 누르면 그 장면으로 |
| 전체 대본 | 지금 말하는 줄 표시, 대본에서 찾기, 자막(CC)으로도 켤 수 있음 |
| 고치기 | 요약과 구간을 손으로 고침. 고친 것은 AI 가 덮어쓰지 않음 |
| 말한 내용으로 검색 | 제목에 없어도 영상에서 말한 단어로 찾음 |
| 자막 파일 올리기 | 음성 인식이 없어도 .srt/.vtt 로 대본을 넣을 수 있음 |

켜는 법: 서버에서 `module/tools/install_stt.sh` 한 번(음성 인식), 환경변수 `SUNSUTUBE_LLM_URL`(AI 주소, 예 `http://127.0.0.1:8000/v1`). 둘 다 없어도 나머지 기능은 그대로 동작한다.
한계: 말이 없는 영상은 핵심을 못 고른다. AI 가 고른 핵심은 틀릴 수 있어 고치기를 둔다.

## 로그인이 없어서 생기는 한계
- 누구나 고치기·지우기·관리 화면을 쓸 수 있다. 로그인을 붙이면 본인 영상과 관리자로 제한한다.
- 좋아요·싫어요는 브라우저마다 한 번이다(브라우저를 바꾸면 다시 누를 수 있다).
