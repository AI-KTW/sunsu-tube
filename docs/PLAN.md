# 순수튜브 계획

원칙: 유튜브의 기본 틀을 먼저 완성하고, 기능은 협의해서 하나씩 더한다.

## 1차: 기본 틀 (완료)
- 홈(카드 목록), 올리기(진행률), 자동 720p 압축과 썸네일, 보기 화면(재생·건너뛰기), 검색, 분류, 정렬, 좋아요, 조회수, 댓글, 고치기·지우기, 저장 공간 표시

## 보류 (기능 완성 후 협의)
- 로그인, 채널, 구독, 재생 목록
- AI 기능(자막, 내용 검색, 요약 등)

## 설치
상수iN 모듈 형식(`module/` 폴더 = `sunsutube-module`). 서버에 ffmpeg 가 필요하다(없으면 압축 없이 원본 저장).
