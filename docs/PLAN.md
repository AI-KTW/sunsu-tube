# 순수튜브 계획

원칙: 유튜브의 기본 틀을 먼저 완성하고, 기능은 협의해서 하나씩 더한다.

## 1차: 기본 틀 (완료)
홈, 올리기, 자동 압축과 썸네일, 보기 화면, 검색, 분류, 정렬, 좋아요, 조회수, 댓글, 고치기·지우기, 저장 공간 표시

## 로그인이 없어서 생기는 한계
- 누구나 고치기·지우기·관리 화면을 쓸 수 있다. 로그인을 붙이면 본인 영상과 관리자로 제한한다.
- 좋아요·싫어요는 브라우저마다 한 번이다(브라우저를 바꾸면 다시 누를 수 있다).
